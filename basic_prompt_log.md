# Foundational Prompt Log
## Task 1: Text Summarization
### Prompt Input
` Summarize the text below in exactly three bullet points.
Text: "Remote work has rapidly expanded, introducing both opportunities and obstacles
for modern businesses. While remote employees benefit from increased flexibility and
reduced commute times, managers often face communication barriers, tracking
difficulties, and security risks associated with home networks."`
### ChatGPT Output
- Increased flexibility: Remote work offers employees greater flexibility and reduces commuting time.
- Communication challenges: Managers face difficulties maintaining effective communication and tracking employee productivity.
- Security risks: Home networks introduce potential cybersecurity vulnerabilities for businesses.
